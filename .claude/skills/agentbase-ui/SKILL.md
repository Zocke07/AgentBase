# AgentBase interface work

The authority is `BUILD_SPEC.md` (Phase 20) and, while the phase is open,
`docs/design/virtual-office-redesign.md`. This is the short form. When the two
disagree with this file, they win; fix this file.

Presentation is yours to change. Behaviour, the event contract, the reducer's
meanings and the boundaries in `CLAUDE.md` are not.

## Colour: roles, never values

Every colour is a token in `src/styles/tokens.css`, defined three times (light,
dark by system, dark by choice). No other file names a colour or uses
`color-mix()`; `src/design/rules.test.ts` fails if one does.

| Need | Token |
|---|---|
| Behind everything; navigation columns; cards and panels; menus and sheets | `--window`, `--sidebar`, `--content`, `--elevated` |
| Button and field fills | `--control`, `--control-hover`, `--control-pressed` |
| A quiet inset (code, chips, table heads); a hovered row; a selected row; tracks and tags | `--fill`, `--fill-hover`, `--fill-selected`, `--fill-strong` |
| Hairlines; control outlines | `--separator` with `var(--hairline)`; `--border-strong` |
| Text | `--text`, `--muted`, `--faint` |
| The accent as a fill or mark; as text; as a tint; as a tinted edge | `--accent`, `--accent-strong`, `--accent-soft`, `--accent-line` |
| Status and risk | `--good`, `--bad`, `--warn`, `--info`, each with `-soft` and `-line`; `--on-good`, `--on-bad`, `--on-warn`, `--on-accent` for text on a solid fill |
| Floating layers | `--material` with `--material-filter` (add the selector to `styles/materials.css`) |

- `--faint` is the lightest text allowed. It may sit on a plane, a control,
  `--fill` or `--fill-hover`. On `--fill-selected` or `--fill-strong` use
  `--muted` or `--text`.
- Accent-coloured text is `--accent-strong`, never `--accent`.
- Text on `--warn-tint` or `--info-tint` is `--text`.
- Colour means status, risk or the next action. It never decorates, and no
  state rests on colour alone: keep the word or the glyph.
- A new text and ground pairing goes into `CONTRAST_PAIRS` in
  `src/design/tokens.ts`, which holds it to 4.5:1 in both themes.

## Type, space, shape

- Sizes: `--size-large-title` 26, `--size-title-1` 22, `--size-title-2` 17,
  `--size-headline` 15, `--size-body` 15, `--size-control` 14,
  `--size-caption` 13. Nothing is smaller than 13 px. New markup can use the
  `.type-*` classes in `styles/base.css`.
- Titles of 20 px and over add `font-family: var(--font-display)`.
  `--font-mono` is for IDs, payloads and code only.
- Numbers that change or line up get `font-variant-numeric: tabular-nums`
  (class `num`). No uppercase labels.
- Space: `--space-1` to `--space-12` on a 4 px grid.
- Radii: `--radius-chip` 4, `--radius-control` 6, `--radius-card` 10,
  `--radius-panel` 14, `--radius-tile` 20, `--radius-capsule`. A nested corner
  is the outer radius minus the padding between them.
- Depth: `--elevation-card`, `-raised`, `-floating`, `-modal`.

## Parts to reuse

- Icons: `<Icon name size filled label />` from `components/icons/Icon`. To add
  one, copy its shapes from Lucide into `icons/paths.ts`. Never inline an SVG
  icon, and vendor only what is used (a test checks).
- `components/ui/`: `Popover` (anchored panel), `Menu` and `MenuButton`,
  `Sheet` (modal), `IconButton`, `Switch`, `Segmented`. They own focus,
  Escape, outside presses and ARIA; do not rebuild those per component.
- Classes with no behaviour: `.button` (`--primary`, `--small`, `--danger`,
  `--allow`, `--deny`), `.card`, `.status`, `.risk`, `.tag`, `.link`,
  `.icon-button`, and `Skeleton` for loading.
- `lib/platform.ts` sets `data-platform` on `<html>`; nothing else reads the
  user agent. `lib/transparency.ts` sets `data-transparency`.

## Motion

- Animate `transform` and `opacity` only. Springs: `--spring-snappy`
  (controls, menus), `--spring-smooth` (panels, sheets), `--spring-bouncy`
  (arrivals), each with its `-duration` token. Fades use `--dur-quick`,
  `--dur-base`, `--dur-slow` with `--ease-out`. The spring values are
  generated by `lib/springs.ts`; change them there.
- Nothing lifts toward the pointer. A press scales to 0.97.
- The event log, the approval panel and the run summary never animate their
  arrival. The office may, under BUILD_SPEC Phase 20 decision 1: motion comes
  from CSS on the step's DOM, the DOM at rest is a pure function of the event
  prefix, and a loop runs only while an operation is open.
- Inside the run projection: no clock, no random source, no timers that
  remove a visual, no inline styles written by a library. Live and replay
  must render identical DOM (`replayIdentity.test.tsx`).
- The reduced-motion block in `styles/accessibility.css` shrinks durations to
  1 ms so `animationend` still fires. `workbench.css` repeats it; keep them
  in step.

## Accessibility checklist

- Text meets AA in both themes; check the workbench's token page.
- Every control is reachable and usable by keyboard; focus is visible.
- An icon-only control has a name (`IconButton label`).
- A document-level key handler ignores editable fields and anything inside
  `[hidden]`: every section stays mounted.
- Forced colours: a state that was a fill needs an edge or a system colour
  (`@media (forced-colors: active)` in `accessibility.css`).
- Copy is for someone who is not a developer. No em dashes anywhere.

## Seeing and testing it

Run from the repository root. On the maintainer's Mac, tools are not on
PATH; see the memory note on that machine.

```text
just workbench       # every page from fixtures, no sidecar; add pages in src/workbench/pages.tsx
just test-visual     # workbench pages in Chromium and WebKit: screenshots and axe
just test-visual --update    # rewrite the baselines after an intended change
just ui-shots <label>        # the real app from scratch data, both themes, three sizes
just ui-shots <label> --reuse --forced-colors    # or --reduced-motion
just ui-shots --compare a b  # are two sets identical?
just ci              # lint, types and unit tests
```

- `ui-shots` needs ports 5173 and 8790 free; stop any dev server first.
- Fixtures and screenshots come from `src/test/scenarios.ts` and scratch data
  only, never from `.dev/data`: the default space holds a person's portfolio.
- A changed test must be for an intended markup change, and is listed in the
  stage's report.
