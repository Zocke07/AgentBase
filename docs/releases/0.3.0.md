# AgentSpace 0.3.0

Every space is now a Markdown knowledge vault that people and agents share.
The new **Knowledge** section in the left rail browses, edits and previews
ordinary `.md` files in the space folder, follows wikilinks and backlinks,
shows a graph, and searches the same local index that agents use. The folder
is Obsidian-compatible and can be opened in Obsidian, but Obsidian is optional.

## Retrieval that shows its work

When a run starts, AgentSpace retrieves the most relevant note excerpts for the
goal, and again for each worker's handoff, and sends them to the model as
cited, untrusted reference material. Ranking is local: BM25 plus a
deterministic hashed term vector, with title, heading and tag signals. Nothing
is sent to an embedding or vector-database service, and an edit made in
another editor is picked up on the next search or run.

**Preview context** on the Home page shows what a goal would retrieve before
you start: each citation, its score, the terms that matched, its token cost,
the total that will be kept, and the provider and model the excerpts are sent
to. Untick a result to keep it out of the run. The run view's **Retrieved
context** lists what the supervisor actually received and what you excluded,
and a replay shows the same.

## A memory inbox instead of silent memory

A successful run writes its goal, outcome and supporting citations to
`memory/runs/<run-id>.md`. Agents that have the new `propose_memory` tool can
propose a memory of their own; the tool is medium risk and asks for approval.
Neither is trusted automatically: memories start as **proposed** and are not
retrieved until you **Approve** or **Pin** them in the **Memory inbox**, where
each one shows its source run, creation date, confidence, tags and citations.
You can also **Edit**, **Archive**, **Merge** several into one, or **Forget**
a memory permanently.

## Vault management

- Move or rename a note and every link to it is rewritten, with a backup.
- Import an existing vault folder, skipping or backing up conflicts.
- Pin favourite notes; filter the browser by tag, pinned, orphan or
  unresolved-link status; unresolved links are marked in a note's metadata.
- Daily notes and notes from `templates/`, with `{{date}}` and `{{title}}`.
- **Save as note** from an agent message or a run's completion in the log.
- **Evaluate** measures retrieval against expected notes (mean reciprocal
  rank and recall) so ranking changes can be checked before relying on them.
- Vaults of up to 10,000 notes are supported and tested.

## Agents and tools

The seeded researcher, writer and reviewer roles gain `search_knowledge` (low
risk) and `propose_memory` (medium risk) unless their allowlist was edited.
Both pass through the same approval gate as every other tool. Database
migrations 007 and 008 make only that change.

## Downloads and installation

- **Windows x64:** download `AgentSpace_0.3.0_x64-setup.exe` and run it.
  Installation is per-user and needs no administrator rights. The unsigned
  installer may show SmartScreen's **Windows protected your PC** prompt:
  select **More info**, then **Run anyway**. The installer includes the
  WebView2 bootstrapper.
- **macOS, Apple Silicon:** download
  `AgentSpace_0.3.0_aarch64-apple-darwin.app.zip`, unzip it, drag
  **AgentSpace.app** into **Applications**, and open it. An Intel Mac download
  is not included. No Python, Node or Rust installation is needed.

Both downloads are larger than 0.2.0's because the app now bundles the Codex
App Server runtime that **Sign in with ChatGPT** uses; the macOS archive is
about 135 MB. Nothing is downloaded at run time.

## macOS first launch and keychain access

The app has a complete ad-hoc signature but no trusted Developer ID signature,
and it has not been notarized. After trying to open it, macOS may block it. If
you trust this download, open **System Settings > Privacy & Security**, choose
**Open Anyway**, then confirm **Open**. See Apple's
[instructions for opening an app from an unidentified developer](https://support.apple.com/en-us/102445).

If that option is unavailable, the terminal fallback removes quarantine from
this app only, after you have placed it in Applications:

```console
xattr -dr com.apple.quarantine /Applications/AgentSpace.app
```

On an update, macOS may ask whether AgentSpace can access a key it previously
saved in the login keychain. Enter your Mac login password if requested, and
choose **Allow** or **Always Allow** to let the app read your saved API key.
Ad-hoc signed builds can prompt again when their code identity changes. Keys
stay in the OS keychain and are passed to the local backend over stdin.

## Upgrade notes

Quit AgentSpace before replacing the app. The existing database, spaces and
files are preserved in the application data directory; existing files in a
space folder appear in Knowledge as soon as it opens. Note excerpts retrieved
for a run reach the selected model like the rest of the prompt, so keep notes
that must never leave the machine in a space you do not run cloud models in.

The API remains bound to `127.0.0.1`. Local embedding models, attachments,
PDFs and web clipping are not part of this release.
