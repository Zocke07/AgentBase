# AgentSpace 0.4.4

Guards against a run that keeps failing the same way, a ceiling on what one
run may spend, and the agents' data files editable in the app. The database
gains migration 014 (a space's own run cost ceiling); `/settings`, `/spaces`
and the run's `run.started` limits gain `max_run_cost_micros`, and
`/spaces/{id}/knowledge/files` and `.../file` are new; the sandbox and the
budget ledger's accounting are unchanged. See the [0.4.3](0.4.3.md) notes
for the previous fixes, still current here.

## What changed

- **An answer cut off at the output limit is not run as a broken call.**
  A model writing one large file in a single tool call could exceed the
  4096-token output limit; the call arrived truncated, read as a missing
  argument, and the model retried the same thing at a full context window
  until the step limit. Answers may now carry 16,384 tokens, and one that
  still hits the limit is logged as cut off, with the model told to write
  less at a time instead of shown a missing argument.
- **An agent that repeats itself is stopped.** Three identical failures in
  a row, or the identical call made three times in a row, end the agent
  with the reason **stopped after failing the same way three times**; the
  supervisor is told and can finish without it, and a supervisor that is
  the one repeating fails the run with that reason.
- **Dollars per run.** A new limit beside steps, agents and seconds: a run
  that has spent it stops where it stands, checked from the ledger before
  each model call. $2.00 by default, per space under Space settings, 0 for
  no ceiling beyond the monthly cap. The Schedules readout names it.
- **Data files in Knowledge.** A **Data files** tab beside **Files** lists
  the plain-text files in the space folder that are not notes (`.json`,
  `.csv`, `.txt`, `.yaml` and the like), the configuration and data the
  agents read and write. Edit one in place and **Save file**; JSON that does
  not parse is refused before it is written. **New file** takes a path, an
  empty list offers the investment roster's three config files as
  templates, and **Delete…** keeps a copy under `.agentspace/backups/`.

## Downloads and installation

- **Windows x64:** download `AgentSpace_0.4.4_x64-setup.exe` and run it.
  Installation is per-user and needs no administrator rights. The unsigned
  installer may show SmartScreen's **Windows protected your PC** prompt:
  select **More info**, then **Run anyway**. The installer includes the
  WebView2 bootstrapper.
- **macOS, Apple Silicon:** download `AgentSpace_0.4.4_aarch64.dmg`, open
  it, drag **AgentSpace** onto the **Applications** link, eject the image and
  open the app from Applications. If a copy from an earlier release is still
  in Downloads, delete it. An Intel Mac download is not included. No Python,
  Node or Rust installation is needed.

## macOS first launch and keychain access

The app has a complete ad-hoc signature but no trusted Developer ID signature,
and it has not been notarized. After trying to open it, macOS may block it. If
you trust this download, open **System Settings > Privacy & Security**, choose
**Open Anyway**, then confirm **Open**. See Apple's
[instructions for opening an app from an unidentified developer](https://support.apple.com/en-us/102445).

If that option is unavailable, the terminal fallback removes quarantine from
this app only, after you have placed it in Applications:

```console
xattr -dr com.apple.quarantine /Applications/AgentSpace.app
```

On an update, macOS may ask whether AgentSpace can access a key it previously
saved in the login keychain. Enter your Mac login password if requested, and
choose **Allow** or **Always Allow** to let the app read your saved API key.
Ad-hoc signed builds can prompt again when their code identity changes. Keys
stay in the OS keychain and are passed to the local backend over stdin.

## Upgrade notes

Quit AgentSpace before replacing the app. The existing database, spaces,
files and a fetched ChatGPT runtime are preserved in the application data
directory; the first launch applies migration 014 to it. Every run now has
a $2.00 ceiling unless you raise it under **Settings → Limits and
approvals** or per space; an overnight pipeline that legitimately costs
more needs a higher figure there before it is scheduled. The API remains bound to
`127.0.0.1`; the only network use beyond your chosen model provider is the
one-time runtime download from `files.pythonhosted.org` when ChatGPT sign-in
is first used.
