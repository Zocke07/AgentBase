# AgentSpace 0.2.0

Spaces give each project its own agents, folder, model and run rules. The desktop
now has a left navigation rail, a Home page for each space, light and dark themes,
plain-language event descriptions, and a docked approval panel. Global API keys
are under **Settings > Keys**. Existing runs, agents and workspace files move
into the default **Main** space on upgrade.

This release adds a macOS download alongside the Windows installer. Telegram has
been removed; Discord remains available, with a setting to choose its space.

## Downloads and installation

- **Windows x64:** download `AgentSpace_0.2.0_x64-setup.exe` and run it. Installation
  is per-user and needs no administrator rights. The unsigned installer may show
  SmartScreen's **Windows protected your PC** prompt: select **More info**, then
  **Run anyway**. The installer includes the WebView2 bootstrapper.
- **macOS, Apple Silicon:** download `AgentSpace_0.2.0_aarch64-apple-darwin.app.zip`,
  unzip it, drag **AgentSpace.app** into **Applications**, and open it. An Intel
  Mac download is not included. No Python, Node or Rust installation is needed.

## macOS first launch and keychain access

The app is unsigned and has not been notarized. After trying to open it, macOS may
block it. If you trust this download, open **System Settings > Privacy & Security**,
choose **Open Anyway**, then confirm **Open**. See Apple's
[instructions for opening an app from an unidentified developer](https://support.apple.com/en-us/102445).

If that option is unavailable, the terminal fallback removes quarantine from this
app only, after you have placed it in Applications:

```console
xattr -dr com.apple.quarantine /Applications/AgentSpace.app
```

On an update, macOS may ask whether AgentSpace can access a key it previously saved
in the login keychain. Enter your Mac login password if requested, and choose
**Allow** or **Always Allow** to let the app read your saved API key. Unsigned builds
can prompt again when their code identity changes. If access is denied, the app
reports the keychain error; reopen it and allow access to use the saved key. Keys
stay in the OS keychain and are passed to the local backend over stdin.

## Upgrade notes

Quit AgentSpace before replacing the app. The existing database and files are
preserved in the application data directory. The new space folders are owned by
AgentSpace; **Space settings > Open folder** opens the selected space's files.

The API remains bound to `127.0.0.1`; the monthly budget and saved credentials are
shared across spaces. Space approval rules can only restrict the global policy.
