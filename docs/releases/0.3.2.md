# AgentSpace 0.3.2

Three fixes from the first macOS field report. Nothing about knowledge,
memory, runs or the ChatGPT runtime changes; see the [0.3.0](0.3.0.md) and
[0.3.1](0.3.1.md) notes for those.

## What changed

- **macOS ships as a disk image.** Earlier releases were a zip, and the app
  usually stayed in Downloads. macOS starts a quarantined app outside
  Applications from a temporary copy on every launch, so Finder searches
  showed several AgentSpace entries and Spotlight listed none. The new
  `.dmg` opens with the app beside an **Applications** link: drag it there,
  eject the image, and open it from Applications. The app bundle itself is
  unchanged.
- **Restart from Settings.** Keys are read from the OS keychain when the app
  starts, so a saved or cleared key needs a restart. **Settings > Keys** now
  offers **Restart AgentSpace** as soon as a key changes; it stops the local
  backend cleanly and reopens the app. Provider, model and other settings
  still apply on **Save settings** without a restart.
- **Dated Claude snapshots are priced.** A space or agent that named
  `claude-haiku-4-5-20251001` was refused with "no price is registered".
  Anthropic prices a dated snapshot exactly as its alias, so any
  `claude-...-YYYYMMDD` id whose alias is in the price table is now charged at
  the alias's rate. Ids outside the table are still refused rather than run
  for free, and OpenAI's differently shaped snapshot ids are not covered.

## Downloads and installation

- **Windows x64:** download `AgentSpace_0.3.2_x64-setup.exe` and run it.
  Installation is per-user and needs no administrator rights. The unsigned
  installer may show SmartScreen's **Windows protected your PC** prompt:
  select **More info**, then **Run anyway**. The installer includes the
  WebView2 bootstrapper.
- **macOS, Apple Silicon:** download `AgentSpace_0.3.2_aarch64.dmg`, open
  it, drag **AgentSpace** onto the **Applications** link, eject the image and
  open the app from Applications. If a copy from an earlier zip is still in
  Downloads, delete it. An Intel Mac download is not included. No Python,
  Node or Rust installation is needed.

## macOS first launch and keychain access

The app has a complete ad-hoc signature but no trusted Developer ID signature,
and it has not been notarized. After trying to open it, macOS may block it. If
you trust this download, open **System Settings > Privacy & Security**, choose
**Open Anyway**, then confirm **Open**. See Apple's
[instructions for opening an app from an unidentified developer](https://support.apple.com/en-us/102445).

If that option is unavailable, the terminal fallback removes quarantine from
this app only, after you have placed it in Applications:

```console
xattr -dr com.apple.quarantine /Applications/AgentSpace.app
```

On an update, macOS may ask whether AgentSpace can access a key it previously
saved in the login keychain. Enter your Mac login password if requested, and
choose **Allow** or **Always Allow** to let the app read your saved API key.
Ad-hoc signed builds can prompt again when their code identity changes. Keys
stay in the OS keychain and are passed to the local backend over stdin.

## Upgrade notes

Quit AgentSpace before replacing the app. The existing database, spaces,
files and a fetched ChatGPT runtime are preserved in the application data
directory. The API remains bound to `127.0.0.1`; the only network use beyond
your chosen model provider is the one-time runtime download from
`files.pythonhosted.org` when ChatGPT sign-in is first used.
