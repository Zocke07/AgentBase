# AgentSpace 0.4.5

A complete local visualization workspace over the files agents already use.
The release adds no database migration and no network service. Chart data,
saved definitions, dashboards and diagrams are ordinary files inside a space,
and an agent writing one still passes through the existing approval gate.

## What changed

- **Charts from agent data.** The new **Visualize** section reads CSV, TSV,
  JSON, JSONL and NDJSON and draws bar, line, area, scatter, pie and metric
  charts or an accessible table. Choose dimensions, multiple values, a series,
  aggregation, sort and a bounded row limit. Export the graphic as SVG or its
  prepared rows as CSV.
- **Portable visualization files.** Saving creates a versioned `.viz.json`
  definition that points to its source file. It is deliberately small enough
  for an agent to create with `write_file`, and is validated before rendering.
- **Dashboards.** Compose saved charts in one, two or three columns and save
  the composition as `.dashboard.json`. Each chart keeps its source, settings,
  accessible table and export controls.
- **Mermaid.** Edit `.mmd` and `.mermaid` beside a live preview, with SVG
  export. Mermaid runs locally in strict mode with HTML labels disabled; the
  returned SVG is parsed again and scripts, embedded objects, event handlers
  and external links are removed before insertion.
- **RAG and memory metrics.** Retrieval results show relevance bars on Home,
  in Knowledge search and in recorded run context. Retrieval evaluation draws
  MRR and recall at k overall and per case. The memory inbox shows the trust
  state distribution. The existing knowledge and run graphs and Usage day
  chart remain unchanged.

The version-one chart and dashboard contracts and agent examples are in the
[visualization guide](../user_guide/7_visualizations.md).

## Downloads and installation

- **Windows x64:** download `AgentSpace_0.4.5_x64-setup.exe` and run it.
  Installation is per-user and needs no administrator rights. The unsigned
  installer may show SmartScreen's **Windows protected your PC** prompt:
  select **More info**, then **Run anyway**. The installer includes the
  WebView2 bootstrapper.
- **macOS, Apple Silicon:** download `AgentSpace_0.4.5_aarch64.dmg`, open it,
  drag **AgentSpace** onto the **Applications** link, eject the image and open
  the app from Applications. It is ad-hoc signed and not notarized, so the
  first open may require **System Settings → Privacy & Security → Open Anyway**.

Quit AgentSpace before replacing an earlier copy. The existing database,
spaces, files and fetched ChatGPT runtime are preserved. `.mmd` and `.mermaid`
join the plain-text extensions the Knowledge API may edit; hidden paths and
files outside the space remain refused.
