# AgentSpace 0.3.3

A frontend-only release. Nothing about the sidecar, the event contract, the
sandbox or the budget ledger changes; see the [0.3.2](0.3.2.md) notes for the
disk image, the restart button and dated snapshot pricing, still current here.

## What changed

- **The run canvas reads as a workflow.** Runs used to show agents as bare
  boxes with a raw activity string. The canvas now reads left to right:
  the goal that started the run, the supervisor, the workers it handed work
  to, and the outcome, each a card with a state pill, a plain sentence for
  what it is doing, and chips that sum what it did with each tool (executed,
  denied, or running now). Click a card to open an inspector with the
  agent's last message, its handoffs and every tool call with its result.
- **The Knowledge section is laid out like an Obsidian vault**, because the
  space folder already is one. A folder tree that folds, a note head with
  its path, tags and properties, source and preview together, and a links
  pane beneath the note for linked mentions, outgoing links and unresolved
  names. Typing `[[` in the editor offers note names to complete the link;
  Ctrl/Cmd+O opens a quick switcher that also creates a note that does not
  exist yet; Ctrl/Cmd+S saves and Ctrl/Cmd+E cycles the view; a task ticked
  in the preview is written back to the source; a tag clicked anywhere
  filters the tree; the graph can be scoped to just the open note's
  neighbours. Unsaved changes ask before another note replaces them.
- **The Obsidian dialect renders properly.** A new Markdown renderer reads
  wikilinks with aliases and headings, embeds, tags, highlights,
  strikethrough, callouts (`> [!tip]`, foldable with `-`), nested and task
  lists, tables and fenced code, and a single newline as a line break, the
  way Obsidian does. It builds elements from a parsed tree and never turns a
  note's or a model's text into markup. The same renderer now shows the
  supervisor's summary, an opened event-log row's prose, and a memory's
  outcome, wherever they appeared as raw text before.
- **Citations open the note they cite.** On Home's retrieved-context preview
  and in a run's "Retrieved context", a citation now opens the note in
  Knowledge instead of sitting there as unclickable text.
- **The rail shows what is waiting.** A badge on **Runs** counts approvals
  waiting and one on **Knowledge** counts proposed memories; Ctrl/Cmd+1
  through 6 jump between sections in rail order.

## Downloads and installation

- **Windows x64:** download `AgentSpace_0.3.3_x64-setup.exe` and run it.
  Installation is per-user and needs no administrator rights. The unsigned
  installer may show SmartScreen's **Windows protected your PC** prompt:
  select **More info**, then **Run anyway**. The installer includes the
  WebView2 bootstrapper.
- **macOS, Apple Silicon:** download `AgentSpace_0.3.3_aarch64.dmg`, open
  it, drag **AgentSpace** onto the **Applications** link, eject the image and
  open the app from Applications. If a copy from an earlier release is still
  in Downloads, delete it. An Intel Mac download is not included. No Python,
  Node or Rust installation is needed.

## macOS first launch and keychain access

The app has a complete ad-hoc signature but no trusted Developer ID signature,
and it has not been notarized. After trying to open it, macOS may block it. If
you trust this download, open **System Settings > Privacy & Security**, choose
**Open Anyway**, then confirm **Open**. See Apple's
[instructions for opening an app from an unidentified developer](https://support.apple.com/en-us/102445).

If that option is unavailable, the terminal fallback removes quarantine from
this app only, after you have placed it in Applications:

```console
xattr -dr com.apple.quarantine /Applications/AgentSpace.app
```

On an update, macOS may ask whether AgentSpace can access a key it previously
saved in the login keychain. Enter your Mac login password if requested, and
choose **Allow** or **Always Allow** to let the app read your saved API key.
Ad-hoc signed builds can prompt again when their code identity changes. Keys
stay in the OS keychain and are passed to the local backend over stdin.

## Upgrade notes

Quit AgentSpace before replacing the app. The existing database, spaces,
files and a fetched ChatGPT runtime are preserved in the application data
directory. The API remains bound to `127.0.0.1`; the only network use beyond
your chosen model provider is the one-time runtime download from
`files.pythonhosted.org` when ChatGPT sign-in is first used.
