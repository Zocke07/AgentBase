# AgentBase 0.4.7

This patch release fixes the built-in news scanner and makes AgentBase easier
to understand and use across window sizes and accessibility settings. It is
the first feature release after the AgentBase rename in 0.4.6.

## What changed

- **Complete news feeds.** `news-scanner` now uses a dedicated RSS and Atom
  reader instead of receiving the first 20,000 characters of a feed. It reads
  complete entries, normalizes publication dates and publisher domains,
  creates deterministic SHA-1 IDs, and supplies title deduplication keys.
- **Bounded and defensive feed parsing.** Feed downloads stop at 2 MB and
  return at most 20 entries. Private addresses, redirects, malformed or unsafe
  XML, non-web item links and oversized input are refused. HTML, script and
  style markup is removed before entry text reaches the model.
- **Safe scanner upgrade.** Migration 015 updates the built-in scanner only
  when its prompt and tool list are still the shipped values. A customized
  scanner is left unchanged.
- **A clearer interface.** Setup, provider errors, model names, spending and
  run states use plain language. Settings puts provider and keys first and
  keeps its save action in reach.
- **Responsive and accessible behavior.** The rail becomes a drawer in narrow
  windows, dense run controls wrap, and short windows retain the run summary.
  Text contrast, keyboard focus, screen-reader labels, a skip link, forced
  colours and reduced-motion behavior were improved.
- **Calmer motion and loading states.** Menus, sections, the tour and other
  window chrome have lightweight transitions and skeleton placeholders.
  Log-driven run content remains still.

## Downloads and installation

- **Windows x64:** download `AgentBase_0.4.7_x64-setup.exe` and run it.
  Installation is per-user and needs no administrator rights. The unsigned
  installer may show SmartScreen's **Windows protected your PC** prompt:
  select **More info**, then **Run anyway**. The installer includes the
  WebView2 bootstrapper.
- **macOS, Apple Silicon:** download `AgentBase_0.4.7_aarch64.dmg`, open it,
  drag **AgentBase** onto the **Applications** link, eject the image and open
  the app from Applications. If a copy is still in Downloads, delete it. An
  Intel Mac download is not included. No Python, Node or Rust installation is
  needed.

Quit AgentBase before replacing an earlier copy. Existing settings, keys,
spaces, files, runs and memories are preserved. On first launch, migration 015
updates an untouched built-in `news-scanner`; rerun the watchlist scan to
replace the earlier empty result. If you customized that scanner, add
`read_feed` to its tools and adapt its prompt manually.

AgentBase remains ad-hoc signed and is not notarized on macOS. Follow the
[installation guide](../user_guide/1_getting_started.md) for Gatekeeper and
keychain guidance. Users upgrading from AgentSpace should first read the
[0.4.6 rename notes](0.4.6.md).
