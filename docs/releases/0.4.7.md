# AgentBase 0.4.7

This first post-rename feature release fixes the built-in news scanner and
improves clarity, responsiveness, and accessibility.

## What changed

- **Complete feeds.** `news-scanner` uses dedicated RSS/Atom input instead of
  a 20,000-character prefix, with complete normalized entries, deterministic
  SHA-1 IDs, and title-deduplication keys.
- **Bounded defensive parsing.** Downloads stop at 2 MB and 20 entries;
  private addresses, redirects, unsafe/malformed XML, non-web links, and
  oversized input are refused. HTML/script/style markup is stripped.
- **Safe scanner upgrade.** Migration 015 changes only scanners retaining
  shipped prompt and tools; customized scanners stay unchanged.
- **Clearer UI.** Setup, provider errors, models, spend, and run states use
  plain language; Settings leads with provider/keys and keeps Save reachable.
- **Responsive, accessible UI.** Narrow rails become drawers, dense controls
  wrap, and short windows retain summary. Contrast, keyboard focus, screen
  reader labels, skip link, forced colours, and reduced motion improved.
- **Calmer chrome.** Menus, sections, tour, and loading use lightweight
  transitions/skeletons; log-driven run content stays still.

## Downloads and installation

- **Windows x64:** run `AgentBase_0.4.7_x64-setup.exe`. It installs per-user
  without admin rights and includes WebView2. For unsigned-app SmartScreen,
  choose **More info → Run anyway**.
- **macOS Apple Silicon:** open `AgentBase_0.4.7_aarch64.dmg`, drag
  **AgentBase** to **Applications**, eject, then open it there. Delete
  Downloads copies. No Intel build or Python/Node/Rust installation exists.

Quit before replacing an earlier copy. Settings, keys, spaces, files, runs, and
memories persist. First launch migrates an untouched built-in `news-scanner`;
rerun its watchlist scan to replace earlier empty results. Customized scanners
need `read_feed` added and their prompts adapted manually.

AgentBase remains ad-hoc signed and unnotarized on macOS. See the
[installation guide](../user_guide/1_getting_started.md) for Gatekeeper/keychain
guidance; AgentSpace upgraders should first read [0.4.6](0.4.6.md).
