# AgentBase 0.5.0

This release changes how AgentBase looks and works. It has a new look made
to feel at home on macOS and Windows, and a run is drawn as an office where
you can watch your agents work. Spaces now run on their own by default: on
a schedule, in chains, within limits you set. The Main space ships a
complete investment research pipeline, and a market watch alerts you to
sudden price moves.

## What changed

### A new look, and a run drawn as an office

- **A run is an office.** Each agent has a desk: the supervisor in front, a
  desk for each worker behind. Work handed on travels as a folder, every
  tool call appears as a slip on the desk and gets a stamp when it is done
  or refused, and each figure's pose says what its agent is doing: asking
  its model, thinking, using a tool, or waiting for you. What an agent says
  is shown as what it said; what its tools did is shown as what happened.
  Click a desk for everything that agent said and did. The cards-and-arrows
  diagram is gone.
- **Play a run back.** The timeline under the office plays a finished run at
  1x to 8x, steps one event at a time, and jumps between the moments that
  mattered: work handed on, questions, refusals, errors, files written.
- **Find anything.** Press Ctrl+K (Command+K on a Mac) or the magnifying
  glass to find a section, an action, a space, a run, an agent or a note.
  Ctrl+comma (Command+comma) opens Settings.
- **Right-click menus** on runs, agents, notes and folders, and the office's
  desks. Shift+F10 or the Menu key opens the same menu from the keyboard.
- **Agents as desks.** Each agent is a desk card with its role, model, tools
  by risk and an Available switch; a desk opens its editor at the side.
- **Home shows what is going.** A desk lights over each run in progress and
  raises a card when it waits for you; when nothing runs, Home says when the
  space next runs on its own. On a wide window Home is two columns, and
  Settings lists its sections at the left.
- **Knowledge.** A note's tags, properties and links sit beside it. Space on
  a note in the Notes list shows a preview without leaving the note you are
  on.
- **Usage** is easier to read: the busiest day labelled, each day's figures
  on hover and as a table, and each model's share of the cost. Chart colours
  stay distinct for colour-blind readers.
- **Throughout:** a toolbar with each section's name, a clearer sidebar,
  settings laid out as rows, empty sections that say what to do next, a
  calmer start screen, sections that fade into one another, and a clearer
  keyboard focus ring. On macOS the window's buttons sit in the toolbar row,
  and dragging the toolbar's empty space moves the window.

### Spaces that work on their own

- **Automations come first.** A space can run a goal daily, weekly, every
  few hours, or straight after another schedule's run completes, in chains
  of up to four stages. **Run once** is for a single task.
- **Autonomous by default.** New installs answer low and medium risk calls
  by policy; a shell command, or anything else the policy does not answer,
  still asks. The log and the run summary say which rule let each call run.
  **Step through** asks before every call when you want to watch closely.
- **Guards for unattended runs.** A network call runs on its own only for a
  site you have listed; a run stops before the model call that would cross
  its cost limit; a scheduled run's unanswered question expires so the run
  carries on; agents cannot write into saved memory or hidden folders.
- **A sleeping computer is respected.** Nothing starts until the computer
  has been awake two minutes, and a going run keeps the computer from idle
  sleep.

### The investment pipeline, in Main

- Main ships a research roster as a switched-off daily pipeline: market and
  news collection, bull and bear theses, a risk check, a daily decision
  table for you to review, and weekly knowledge and review stages. Nothing
  is ever bought or sold.
- Four deterministic tools read prices, compute the portfolio, check your
  limits and score predictions, so figures are calculated, not guessed.
  Forecasts for 1, 2, 3, 5 and 21 trading days go into a monthly Excel
  workbook and are scored as actual prices arrive.
- **My portfolio** on Home edits your holdings, cash, watched stocks and
  limits. The pipeline, its tools, the portfolio editor and the market watch
  belong to Main; other spaces use the general tools.

### Market watch

- While AgentBase is open, the market watch checks your holdings, watchlist
  and indexes every few minutes in US trading hours. A sudden move becomes an
  alert on Home, a desktop notification and, if you set one, a Discord
  message, and an agent writes up why it may have moved.

### Knowledge, models and costs

- Knowledge opens on **User Summary**, the results written for you to read,
  with **Technical Details** for the raw data. The **Journal** reads every
  dated report as one page; a data file draws as a chart.
- Claude Sonnet 5.5 and Haiku 5.5 and GPT-6.1 Sol are in the catalogue, and
  a ChatGPT plan is limited to the models it includes.
- Prompt caching makes repeated runs cheaper, and cached tokens are charged
  at published rates. A model at capacity is waited for instead of failing
  the run.

## Things to know before upgrading

- **Not yet checked on Windows.** The redesign was built and checked on
  macOS. The Windows installer is built and its install and engine start
  are tested, but the new look has not yet been seen on a Windows PC.
- **Windows builds made since the market watch (Phase 18) could not start
  their engine**, because Windows has no built-in time-zone database. This
  release includes that database, and its Windows installer is tested to
  start its engine. 0.4.8 was not affected.
- On first launch, database migrations 017 to 036 run. An upgraded install
  keeps the approval answers it had (migration 018) rather than taking the
  new autonomous default; you can change them in Settings.
- The investment pipeline's schedules arrive switched off. A schedule whose
  time passed while AgentBase was closed runs once at the next launch (or is
  skipped, per its setting), and it spends from your provider account.
- Schedules and the market watch run only while AgentBase is open. There is
  no tray or background service.

## Downloads and installation

- **Windows x64:** download `AgentBase_0.5.0_x64-setup.exe` and run it.
  Installation is per-user and needs no administrator rights. The unsigned
  installer may show SmartScreen's **Windows protected your PC** prompt:
  select **More info**, then **Run anyway**. The installer includes the
  WebView2 bootstrapper.
- **macOS, Apple Silicon:** download `AgentBase_0.5.0_aarch64.dmg`, open it,
  drag **AgentBase** onto the **Applications** link, eject the image and open
  the app from Applications. If a copy is still in Downloads, delete it. An
  Intel Mac download is not included. No Python, Node or Rust installation is
  needed.

Quit AgentBase before replacing an earlier copy. Existing settings, keys,
spaces, files, runs and memories are preserved.

AgentBase remains ad-hoc signed and is not notarized on macOS. Follow the
[installation guide](../user_guide/1_getting_started.md) for Gatekeeper and
keychain guidance. Users upgrading from AgentSpace should first read the
[0.4.6 rename notes](0.4.6.md).
