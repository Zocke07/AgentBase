# AgentSpace 0.3.1

A smaller, faster-starting build of 0.3.0. Nothing about knowledge, memory or
runs changes; see the [0.3.0 notes](0.3.0.md) for those.

## What changed

0.3.0 froze the OpenAI Codex App Server runtime, which **Sign in with
ChatGPT** uses, into the app's backend. That made both downloads about five
times larger and, because the backend unpacks everything it carries each time
the app starts, roughly doubled the time to a ready window for everyone,
including people who only use API keys.

In 0.3.1 the runtime is no longer shipped. The first time you choose **Sign in
with ChatGPT**, AgentSpace downloads the exact runtime build this release was
tested with (about 113 MB on macOS, 138 MB on Windows) from PyPI into its data
folder, refuses it unless its size and SHA-256 checksum match, and keeps it
for every later launch. Settings shows the progress, and the browser sign-in
opens by itself once the download completes. Signed-in accounts, API keys and
existing data are unaffected by the upgrade; the runtime is fetched the next
time you sign in.

- Windows installer: about 50 MB, down from 163 MB.
- macOS archive: about 25 MB, down from 135 MB.
- App start on an Apple Silicon Mac: about 1 s to a ready backend, down from
  about 2 s.
- API-key access never downloads the runtime.

## Downloads and installation

- **Windows x64:** download `AgentSpace_0.3.1_x64-setup.exe` and run it.
  Installation is per-user and needs no administrator rights. The unsigned
  installer may show SmartScreen's **Windows protected your PC** prompt:
  select **More info**, then **Run anyway**. The installer includes the
  WebView2 bootstrapper.
- **macOS, Apple Silicon:** download
  `AgentSpace_0.3.1_aarch64-apple-darwin.app.zip`, unzip it, drag
  **AgentSpace.app** into **Applications**, and open it. An Intel Mac download
  is not included. No Python, Node or Rust installation is needed.

## macOS first launch and keychain access

The app has a complete ad-hoc signature but no trusted Developer ID signature,
and it has not been notarized. After trying to open it, macOS may block it. If
you trust this download, open **System Settings > Privacy & Security**, choose
**Open Anyway**, then confirm **Open**. See Apple's
[instructions for opening an app from an unidentified developer](https://support.apple.com/en-us/102445).

If that option is unavailable, the terminal fallback removes quarantine from
this app only, after you have placed it in Applications:

```console
xattr -dr com.apple.quarantine /Applications/AgentSpace.app
```

On an update, macOS may ask whether AgentSpace can access a key it previously
saved in the login keychain. Enter your Mac login password if requested, and
choose **Allow** or **Always Allow** to let the app read your saved API key.
Ad-hoc signed builds can prompt again when their code identity changes. Keys
stay in the OS keychain and are passed to the local backend over stdin.

## Upgrade notes

Quit AgentSpace before replacing the app. The existing database, spaces and
files are preserved in the application data directory. The API remains bound
to `127.0.0.1`; the only new network use is the one-time runtime download
from `files.pythonhosted.org` when ChatGPT sign-in is first used.
