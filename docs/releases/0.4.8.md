# AgentBase 0.4.8

This patch release steadies the Runs window, makes a run and the month's
spending easier to follow, and lets each space keep its own AI provider, with
the newest Claude and GPT models in the list.

## What changed

- **No more flicker on the run canvas.** While a run streamed, the canvas
  redrew every arrow and label about once a frame. It now keeps them in place
  and updates only what changed.
- **A folding event log.** Click **Event log** to fold the log to one line
  naming the latest step; the canvas takes the room. Unfold it to find your
  place and filters as you left them. The window remembers the choice.
- **Named start-up stages.** Instead of "Starting up (try 37)", the start screen
  shows what it is waiting on (**Starting the engine**, **Checking your
  settings**, **Loading your spaces**), says when a first start after an update
  is simply slow, and says when an earlier AgentBase is still closing.
- **Where the month's money went.** Click the spending figure in the header for
  a breakdown: what is used and left, this space's share, runs and their
  average cost, the models and spaces that cost the most, and the limit per
  run, with links to **Usage** and to the limits in Settings.
- **Each space keeps its own provider.** The provider in Settings is now only
  where a new space starts; changing it moves no existing space. Change a
  space's provider in **Space settings**: its model moves to the one at the
  same level on the new provider (for example Claude Haiku to GPT-6 Luna, Claude
  Sonnet to GPT-6 Sol), and agents that still name the old provider's models
  are listed, ticked, to move with it.
- **Newer models.** Claude Opus 5.5, GPT-6 Sol and GPT-6 Luna are available,
  and new spaces start on Claude Opus 5.5 or GPT-6 Sol. Model lists show the
  current lineup first, each with its level and price.

## Things to know before upgrading

- On first launch, migration 016 writes the provider each space was using into
  the space, so nothing changes provider.
- Spaces on Claude Opus 5 move to Claude Opus 5.5, which Anthropic now
  recommends and which costs less ($4 in and $20 out per million tokens,
  against $5 and $25). The investment roster's `decision` agent moves too,
  unless you had edited it. Agents you created keep the model they name.
- OpenAI's GPT-6 lineup has no model at Opus's level, so a switch to OpenAI
  maps Opus to GPT-6 Sol, which costs less and may be less capable. Switching
  back maps GPT-6 Sol to Claude Sonnet 5, not Opus. Every mapped model is shown
  before you save, and you can pick another.
- Anthropic may retire Claude Haiku 4.5, which the roster's collectors use, any
  time after 15 October 2026.

## Downloads and installation

- **Windows x64:** download `AgentBase_0.4.8_x64-setup.exe` and run it.
  Installation is per-user and needs no administrator rights. The unsigned
  installer may show SmartScreen's **Windows protected your PC** prompt:
  select **More info**, then **Run anyway**. The installer includes the
  WebView2 bootstrapper.
- **macOS, Apple Silicon:** download `AgentBase_0.4.8_aarch64.dmg`, open it,
  drag **AgentBase** onto the **Applications** link, eject the image and open
  the app from Applications. If a copy is still in Downloads, delete it. An
  Intel Mac download is not included. No Python, Node or Rust installation is
  needed.

Quit AgentBase before replacing an earlier copy. Existing settings, keys,
spaces, files, runs and memories are preserved.

AgentBase remains ad-hoc signed and is not notarized on macOS. Follow the
[installation guide](../user_guide/1_getting_started.md) for Gatekeeper and
keychain guidance. Users upgrading from AgentSpace should first read the
[0.4.6 rename notes](0.4.6.md).
