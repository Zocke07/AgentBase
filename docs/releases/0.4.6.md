# AgentBase 0.4.6

AgentSpace is now AgentBase across product, backend/Rust/npm packages, Tauri
bundle, schemas, environment, CI artifacts, and current docs. There is no
database migration or behavioral change beyond identifiers and the one-time
adoption below. Visualization remains as in [0.4.5](0.4.5.md).

## What changed

- **Current identifiers changed together.** `agentbase`, `agentbase.sqlite3`,
  `dev.agentbase.desktop`, `agentbase-desktop`, `@agentbase/desktop`,
  `@agentbase/schemas`, `AGENTBASE_DATA_DIR`, `agentbase-sidecar-*`, and CI
  names stay aligned through release/hygiene tests.
- **One-time profile adoption.** First canonical launch can adopt a preceding
  AgentSpace profile into an empty default AgentBase app-data directory,
  renaming SQLite/WAL/SHM without overwriting an existing profile. Dev/other
  data directories remain untouched.
- **Legacy reads, AgentBase writes.** Old keychain, browser preference,
  visualization-schema (`agentspace://`), theme, space, panel, and rail values
  read only when no AgentBase value exists; all writes use AgentBase.
- **Not in-place.** New bundle identifiers create separate Windows app entries
  and `AgentBase.app`. Remove the untouched old app after confirming adoption.
- Historical documents retain their true AgentSpace-era names/artifacts.

## Downloads and installation

- **Windows x64:** run `AgentBase_0.4.6_x64-setup.exe`. It installs per-user
  without admin rights and includes WebView2; for SmartScreen, choose **More
  info → Run anyway**.
- **macOS Apple Silicon:** open `AgentBase_0.4.6_aarch64.dmg`, drag to
  **Applications**, eject, then open it there. Delete Downloads copies. No
  Intel build or Python/Node/Rust installation exists.

## macOS first launch and keychain access

The app has a complete ad-hoc signature but no trusted Developer ID signature,
and it has not been notarized. After trying to open it, macOS may block it. If
you trust this download, open **System Settings > Privacy & Security**, choose
**Open Anyway**, then confirm **Open**. See Apple's
[instructions for opening an app from an unidentified developer](https://support.apple.com/en-us/102445).

If that option is unavailable, the terminal fallback removes quarantine from
this app only, after you have placed it in Applications:

```console
xattr -dr com.apple.quarantine /Applications/AgentBase.app
```

On first launch after installing from a prior AgentSpace app, macOS may ask
whether AgentBase can access a key saved in the login keychain under the old
`dev.agentspace.desktop` service; this is the one-time legacy read-through
described above. Enter your Mac login password if requested, and choose
**Allow** or **Always Allow**. Keys stay in the OS keychain and are passed to
the local backend over stdin.

## Upgrade notes

Keep AgentSpace closed during first AgentBase launch for a quiet database.
AgentBase installs alongside it; after confirming spaces, definitions, and
history, remove the old app yourself. API key, Discord token, theme, selected
space, and saved visualizations carry over on first read. API remains on
`127.0.0.1`; beyond model providers, only ChatGPT first sign-in downloads from
`files.pythonhosted.org`.
